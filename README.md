# Minimalist_Autonomous_YouTubePlayer
Легковесный, плеер для YouTube-плейлистов (например, фоновой музыки и клипов) на слабых старых ноутбуках и мини-ПК (проверен на **Intel Celeron N4000C**, Windows 10/11).  Проект полностью избавлен от тяжелых зависимостей (нет Python, нет тяжелых GUI-оболочек) и оптимизирован под максимальную экономию оперативной памяти и процессорных ресурсов.
